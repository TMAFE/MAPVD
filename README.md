This repository contains TMAFE's prototype Microsoft Actor Properties Viewer + Decompiler, which was able to preview embedded WMF data and play back WAV assets inside of .ACT files. Over time, the code would be recycled into what would become Frontier Actor and part of the Universal Character Scripting Helper.

The prototype was made possible through public information from official Microsoft Actor patent filings, hex analysis, image/frame inspection, manual file analysis, and experimentation with ACT files. As a result of being developed from TMAFE's own research, it does not utilize or need any UTOPIA.DLL components from Bob or any MSO97.DLL components from Office.

This prototype was quite basic, and ironically enough read .ACT 2.0 files better than .ACT 1.0 files (like the ones in Bob). This project is part of TMAFE's research on the legacy Microsoft Actor technology that powered Microsoft Bob and the Office 97 Assistant, and you may read some of our research here:

* https://agentpedia.tmafe.com/wiki/Microsoft_Actor
